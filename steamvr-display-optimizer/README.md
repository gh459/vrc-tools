# SteamVR Display Optimizer

SteamVR の起動を即時検知して自動的にディスプレイ構成を最適化（メイン低解像度化・サブ無効化）し、SteamVR 終了時に通常構成へ自動復元する軽量・高信頼性バックグラウンド常駐ツールです。

OSカーネルレベルの同期イベント待機（`WaitForExit`）を採用しているため、**VRゲームプレイ中のCPU使用率は 0.00%（完全ゼロ負荷・フレームレートへの影響なし）** を達成しています。

---

## 🖥️ ディスプレイ構成仕様

| モード | メインモニター (`DISPLAY1`) | サブモニター (`DISPLAY2`) | 説明 |
| :--- | :--- | :--- | :--- |
| **VR モード** (SteamVR 起動中) | **800 × 600** @ 50Hz (最寄り56Hz) | **無効化** (切断) | GPU負荷とVRAM消費を最小化 |
| **通常モード** (SteamVR 終了後) | **1920 × 1080** @ **180Hz** | **1920 × 1080** @ **75Hz** | 高リフレッシュレート通常環境へ自動復帰 |

## 📁 ファイル構成と使い方

用途に合わせて、アイコンをダブルクリックするだけで直感的に操作できます。

| ファイル名 | 操作 | 説明 |
| :--- | :--- | :--- |
| **`Run_SteamVR_Optimizer.bat`** | ダブルクリック | **通常起動**: 黒いコンソール画面で動作ログを確認しながら起動します。 |
| **`Run_SteamVR_Optimizer_Silent.vbs`** | ダブルクリック | **バックグラウンド起動**: ウィンドウを一切出さず、完全に静かに常駐します。 |
| **`Stop_SteamVR_Optimizer.bat`** | ダブルクリック | **停止＆復元**: 常駐している監視を終了し、即座に通常画面構成へ復元します。 |
| **`Install_AutoStart.bat`** | ダブルクリック | **自動起動ON**: Windows起動時に自動でバックグラウンド常駐するように登録します。 |
| **`Uninstall_AutoStart.bat`** | ダブルクリック | **自動起動OFF**: スタートアップからの自動起動登録を解除します。 |

## 🌟 主な機能と特徴

1. **ゼロCPU負荷 (Zero-CPU Engine)**:
   - SteamVR未起動時は1秒間隔の超低負荷監視（CPU 0.01%未満）。
   - SteamVR起動中はOSカーネルイベント待機により **CPU使用率 0.00%**。
2. **Win32 Native CCD トポロジ制御 (`SetDisplayConfig`)**:
   - 外部プロセス（`DisplaySwitch.exe`）を一切介さず、OSカーネルの CCD API を直接同期呼び出し。数ミリ秒での瞬時切替と物理モニター数による成否検証・自動リトライを実現。
3. **自律セルフヒーリング (自己修復ループ)**:
   - Virtual Desktop Streamer のヘッドセット切断時や外部要因により、サブモニターが無効化されたまま放置されたりメイン解像度が狂った場合でも、監視ループが不整合を自動検知して即座に正常状態（拡張画面＋180Hz/75Hz）へ自動復旧。
4. **状態遷移デバウンス (フラッピング防止)**:
   - SteamVR の一時的切断や急激な再起動に対し、2.5秒間の安定化待機を行って過剰な画面切替や GPU ドライバとの競合を防止。
5. **多重プロセス同期**:
   - `vrserver` (サーバー), `vrmonitor` (UI), `vrcompositor` (描画) の全プロセスを追跡。UIウィンドウを途中で閉じてもゲームプレイ中はVRモードを確実に維持します。
6. **Windows ネイティブ通知**:
   - バックグラウンド実行時でも、常駐開始・VRモード適用・通常モード復元時にデスクトップ右下に美しいトースト通知が届きます。
7. **高DPI対応 (Per-Monitor DPI Aware V2)**:
   - Windowsの拡大率（125%、150%など）が設定されていても、常に正確な物理解像度（1920x1080 / 800x600）を制御します。
8. **二重起動防止 (Mutex Guard)**:
   - 誤ってランチャーを2回起動しても、OSミューテックスにより自動的に重複を防止します。
9. **安心のフェイルセーフ**:
   - コンソール強制終了（「×」ボタン）や `Ctrl+C` 中断時でも、自動的に通常画面構成へ復帰します。
10. **自動ローテーションログ**:
   - すべての動作ログは `SteamVR_DisplayOptimizer.log` に自動記録されます（最大50KBで自動ローテーションされるため容量を圧迫しません）。

## ⚙️ 設定のカスタマイズ方法

解像度やリフレッシュレートを変更したい場合は、`SteamVR_DisplayOptimizer.ps1` をメモ帳等で開き、上部の設定パラメータを書き換えるだけで変更できます。

```powershell
# SteamVR起動中（VRモード）
$VR_Width       = 800
$VR_Height      = 600
$VR_Frequency   = 50

# SteamVR終了後（通常モード: メイン）
$Normal_Width     = 1920
$Normal_Height    = 1080
$Normal_Frequency = 180

# SteamVR終了後（通常モード: サブ）
$Sub_Width        = 1920
$Sub_Height       = 1080
$Sub_Frequency    = 75
```
