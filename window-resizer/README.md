# Window Resizer v2.4 (AutoHotkey v2)

アクティブウィンドウの限界極小化（1x1ピクセル・OSリージョンクリッピング）、強制フルスクリーン化（枠線・タイトルバーなし）、および元の状態への完全復元を行う最高精度・超低負荷な常駐ユーティリティです。

## 📁 生成ファイル・プロジェクト構成

- **実行ファイル (EXE)**: `WindowResizer.exe` (v2.4.0.0, 64-bit Standalone)
- **スクリプトソース (AHK)**: `WindowResizer.ahk`
- **設定ファイル (INI)**: `WindowResizer.ini` (ホットキー・縮小ピクセル・音響フィードバック・通知設定・ステルスモードのカスタマイズ)
- **動作ログ (LOG)**: `WindowResizer.log` (操作履歴・エラー・起動停止ログ自動出力、100KB自動ローテーション対応)
- **ビルドスクリプト (BAT)**: `build.bat` (コンパイラ自動探索＆自動再起動・同期ビルド対応)
- **自動起動登録 (BAT)**: `Install_AutoStart.bat` (タスクスケジューラ連携・UACダイアログなしで管理者権限自動常駐)
- **自動起動解除 (BAT)**: `Uninstall_AutoStart.bat` (自動起動解除および実行中プロセス停止)

## ⌨️ ショートカットキー一覧 (WindowResizer.ini で変更可能)

| デフォルトキー | 動作 | 説明 |
|---|---|---|
| `Ctrl + Shift + M` | **限界極小化 1x1 (Toggle)** | アクティブウィンドウのタイトルバー・枠線を解除し、OSの描画領域（Window Region）を物理的に **1x1 ピクセル** にクリッピングして画面左上に配置します。極小化後、**背面のウィンドウへ自動でフォーカスを委譲**（Cloaked/ToolWindow除外）するため作業が中断されません。ステルスモード有効時はタスクバーからも完全に隠れます。 |
| `Ctrl + Shift + F` | **強制全画面 (Toggle)** | タイトルバー・枠線を削除し、アクティブウィンドウを現在のモニター作業領域いっぱいに全画面化します（Windows 11 角丸無効化により四隅の隙間ゼロ）。もう一度押すと復元します。 |
| `Ctrl + Shift + R` | **スマート復元 (LIFOスタック)** | 変更されたウィンドウを復元します。複数ウィンドウを極小化した後でも、**押すたびに直近のウィンドウを新しい順に1つずつ完全復元＆最前面化**します。デスクトップ等にフォーカスがある状態でも迷わず復元可能です。 |

## 🛡️ 品質保証・UX・パフォーマンス最適化仕様（v2.4）

1. **ステルスモード（タスクバー非表示化・トグル切替）**:
   - `HideFromTaskbar` オプションにより、1x1 縮小時にタスクバーアイコン（`WS_EX_APPWINDOW`）を除去し `WS_EX_TOOLWINDOW` を付与することで、タスクバーからも完全に姿を消すステルス化を実現。トレイメニューおよび `WindowResizer.ini` から即時切替可能。
2. **ディスプレイ構成変更耐性（WM_DISPLAYCHANGE 通知ハンドラ）**:
   - モニターの切断・接続、画面解像度変更（`WM_DISPLAYCHANGE = 0x007E`）を常時監視。縮小中のウィンドウが画面外に取り残されることを防ぎ、現在の最寄りモニター作業領域左上へ自動再スナップ。
3. **画面外虚空消失防止（マルチモニター作業領域自動クランプ）**:
   - サブモニターが抜去された状態でウィンドウを復元しようとした場合でも、`EnsureWindowInScreenArea` が座標を検査し、プライマリモニターの安全な可視領域内に自動クランプ。ウィンドウがデスクトップ外の「虚空」に消える問題を根絶。
4. **アトミック描画復元（SetWindowPos 0x0024 による描画ちらつき撲滅）**:
   - 復元時、サイズ変更・位置移動・フレーム変更通知（`SWP_FRAMECHANGED | SWP_NOZORDER`）を Win32 `SetWindowPos` によりアトミックに同時適用。段階的移動による一瞬の描画乱れやちらつきを完全に排除。
5. **トレイメニュー項目の動的グレーアウト（無駄クリック撲滅）**:
   - 変更中のウィンドウが 0 件の時は、トレイメニューの「復元」および「一括復元」項目を自動的に無効化（グレーアウト）。無駄なクリックを未然に防止。
6. **外部設定ファイル (WindowResizer.ini) の自動生成＆自由なカスタマイズ**:
   - ホットキー割り当て（`Shrink`, `Fullscreen`, `Restore`）、極小化サイズ（`TinyWidth`, `TinyHeight`）、音響フィードバック（`SoundFeedback`）、ツールチップ通知（`ShowToolTips`）、ステルスモード（`HideFromTaskbar`）を INI ファイルで完全制御。トレイメニューの「設定ファイルを開く (Config.ini)」から即座に編集可能。
7. **非ブロッキング高速トレイUI（schtasksプロセス生成のキャッシュ完全排除）**:
   - 自動起動判定を内部キャッシュ化。ウィンドウ縮小・復元時のトレイ更新において `schtasks.exe` の同期プロセス起動を完全撤廃し、ホットキー操作時の応答ラグをゼロ化（0.00ms 即時処理）。
8. **洗練された音響フィードバック（MessageBeep / Asterisk）**:
   - 極小化、全画面化、復元が成功した瞬間に控えめなシステム標準通知音を再生。画面のどこにも目線を動かすことなく、手元のキー入力だけで操作の成功を確実に認知可能。
9. **高度なスマート・フォーカス委譲（Cloaked・仮想デスクトップ・ToolWindowの完全除外）**:
   - ウィンドウを 1x1 に縮小した瞬間、Z オーダー直下の背面ウィンドウへ自動でフォーカスを譲渡。Windows 10/11 の UWP 不可視ウィンドウ（`DWMWA_CLOAKED`）やツールウィンドウ（`WS_EX_TOOLWINDOW`）を正確にスキップし、今目の前にある本物のアプリへ確実にフォーカスを移譲。
10. **Per-Monitor DPI Awareness v2 対応（OSスケーリング仮想化の完全排除）**:
    - 4K (150%) と FHD (100%) など、異なる DPI スケーリングが混在するマルチモニター環境において、OS による DPI 仮想化やピクセル補正ブレを根絶。あらゆる解像度・モニター間での移動・復元で 1 ピクセルの狂いもなく元のサイズを復元。
11. **Windows 11 DWM 角丸・ドロップシャドウのアーティファクト完全排除**:
    - `DWMWA_WINDOW_CORNER_PREFERENCE (33)` を動的に制御。1x1 縮小時およびフルスクリーン化時に角丸と非クライアント領域レンダリングを無効化（`DWMWCP_DONOTROUND`）し、画面左上の影ゴミや全画面四隅の隙間を排除。復元時は本来の美しい角丸スタイルへ自動復帰。
12. **トレイメニューからのワンクリック「自動常駐 (Auto-Start)」トグル**:
    - タスクトレイ右クリックメニューに `[✔] Windows 起動時に自動常駐 (有効)` を常時表示。クリックするだけでタスクスケジューラ登録／解除を即座にトグル可能。管理者権限実行時は外部コマンドの画面すら出さずに 0.1 秒で安全完了。
13. **革新的UX: LIFO（後入れ先出し）スマート復元スタック**:
    - 複数のウィンドウを極小化した後、デスクトップや別アプリを見ている状態からでも `Ctrl + Shift + R` を押すだけで、直近に変更したウィンドウから順番に自動復元＆アクティブ化。
14. **終了時のウィンドウ消失保護（Exit Protection）**:
    - 1x1ピクセルのままアプリを終了し、ウィンドウが画面から見失われる重大な事故を防ぐため、変更中ウィンドウが存在する状態で終了しようとした際に「復元して終了」「そのまま終了」「キャンセル」を選択できる安全ダイアログを表示（OSシャットダウン時は自動で全ウィンドウを安全復元）。
15. **トレイダブルクリックによる即時復元**:
    - タスクトレイアイコンをダブルクリックするだけで、直近の変更ウィンドウを即座に元の位置・サイズへ復元＆前面表示。
16. **ホットキー一時停止（Suspend）**:
    - フルスクリーンゲームや他の開発ツールとキーが競合した際、トレイメニューからワンクリックでホットキーを一時停止／再開可能。トレイアイコンとツールチップにも状態を明示。
17. **高速連打・長押し防止（300ms キーデバウンス）**:
    - キー連打による状態の不整合や画面の過度なチラつき・再描画スパムを防止し、確実で滑らかな操作感を実現。
18. **ポーリング負荷ゼロ化（前フレームHWNDキャッシュ短絡）**:
    - アクティブウィンドウ追跡タイマー（200ms）において、直前フレームと HWND が一致する場合は Win32 API 呼び出しを完全バイパスし、CPU負荷を完全なゼロ（0.00%）に抑制。
19. **高信頼性ロギング＆自動ローテーション（オフバイワン修正済）**:
    - 起動・終了、縮小、全画面化、復元、例外などの全イベントを `WindowResizer.log` に自動記録。
    - ログサイズが 100KB を超えた場合は最新 100 行を正確に保持して古い行を切り詰め。トレイメニューの「ログファイルを開く」から即座に閲覧可能。
20. **Win32 API 完全準拠: WS_EX_TOOLWINDOW 座標系の自動分岐**:
    - `GetWindowPlacement` の仕様に基づき、通常のトップレベルウィンドウ（ワークスペース座標系）では `mLeft` / `mTop` を加算し、ツールウィンドウ（`WS_EX_TOOLWINDOW`、元々スクリーン座標系）ではそのまま座標を採用する完全な条件分岐を実装。
21. **最前面表示 (WS_EX_TOPMOST) の正式な Z オーダー復元**:
    - タスクマネージャーやピクチャーインピクチャー等の常時最前面ウィンドウを縮小・復元した際、`SetWindowPos` に `HWND_TOPMOST (-1)` を明示的に指定して最前面属性を 100% 確実に維持。
22. **動的ホットリロード対応（Reload Config）**:
    - アプリを再起動することなく、トレイメニューの「設定を再読み込み」から `WindowResizer.ini` の内容（ホットキー、サイズ、音、ステルス等）を 0ms で即時反映。
23. **多段スマートフォーカス委譲（60階層走査＋トップレベルフォールバック）**:
    - 縮小後のフォーカス譲渡を 60 階層まで探索し、さらに見つからない場合はトップレベルの可視ウィンドウへ安全にフォールバック。キー入力の孤立を完全に防止。
24. **タスクスケジューラ起動時のワーキングディレクトリ（CWD）自動整合**:
    - `SetWorkingDir(A_ScriptDir)` により、OS の自動起動タスク（System32カレント）から起動された場合でも、常にスクリプト自身のフォルダを作業ディレクトリとして保証。
25. **ノートPCバッテリー駆動時の自動常駐完全保証**:
    - タスクスケジューラのデフォルト制約（`DisallowStartIfOnBatteries`, `StopIfGoingOnBatteries`）を PowerShell で自動解除。バッテリー駆動中のログオンでも 100% 確実に自動起動。
26. **フォーカス遷移時の終了済みウィンドウ即時パージ**:
    - 外部で閉じられたウィンドウをフォーカス遷移時に即時検知・登録解除し、トレイメニューのバッジ件数を常にリアルタイムな正確性で維持。
27. **ディスプレイ構成変更時の全画面自動リフィット**:
    - モニター切断や解像度変更時、全画面化中のウィンドウを新しいモニター作業領域へ自動リサイズし、画面はみ出しや隙間の発生を根絶。
28. **設定エラー時の自動フォールバック保護（Fault Tolerance）**:
    - `WindowResizer.ini` で無効・競合するホットキーが指定された場合でも、操作不能に陥らず自動的に既定キー（`^+m`, `^+f`, `^+r`）へフォールバックして動作を継続。
29. **設定ファイル入力値の安全バリデーション＆クランプ（SafeIntIni）**:
    - `WindowResizer.ini` に空文字・不正文字列・負数・0が指定された場合でも、型エラーによる後続設定読み込み中断を防ぎ、物理的許容範囲（例: 幅高さ 1〜500px）へ自動補正。
